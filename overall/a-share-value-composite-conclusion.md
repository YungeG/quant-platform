# A股PIT价值复合策略结论

- **质量因子：DATA-BLOCKED**
- **价值复合：NO-GO**
- **窗口：** 2016-01-04—2026-08-25
- **调仓：** 40次季度决策
- **平均估值覆盖：** Top-500的93.78%

## 1. 数据先行结论

`FinancialIndicatorData`的100,300行ROE/ROA数据全部缺失`AnnDate`，且只覆盖1,200只股票；不能构造PIT质量因子。`IncomeData`虽有公告日，也只覆盖1,200只受限股票集合。

因此本轮没有使用固定财报滞后伪造质量数据，只测试每日PIT的`EP=1/PETTM`与`BP=1/PB`。

## 2. 价值结果

| 组合 | CAGR | Sharpe | 最大回撤 | 相对Top-500市值基准 |
| --- | ---: | ---: | ---: | ---: |
| EP+BP复合50 | 2.11% | 0.206 | -33.24% | **-2.92% CAGR** |
| EP-only 50 | 2.93% | 0.248 | -34.73% | -2.10% CAGR |
| BP-only 50 | 2.52% | 0.227 | -33.70% | -2.52% CAGR |
| Top-500市值加权 | **5.03%** | **0.355** | -38.69% | 基准 |
| Top-500等权 | 2.62% | 0.228 | -39.81% | 诊断 |

价值组合降低了一部分回撤，但收益和Sharpe均没有超过市值加权基准。

## 3. 固定时期

### EP+BP复合50

| 时期 | CAGR | Benchmark CAGR | Excess CAGR |
| --- | ---: | ---: | ---: |
| 2016—2019 | +1.40% | +5.32% | **-3.92%** |
| 2020—2022 | -2.41% | +2.04% | **-4.44%** |
| 2023—2026 | +6.80% | +7.25% | **-0.44%** |

三个时期全部跑输基准，Stage稳定性明确失败。

EP单因子是表现最好的价值版本，但也只有2023—2026产生+1.06%超额，前两个时期均跑输。

## 4. 为什么学术价值因子没有转化为当前策略

1. 学术结果多为多空或宽分位组合，当前只能做50只纯多头；
2. 本轮主动做了行业与规模中性，无法依靠小盘和行业偏离制造收益；
3. 价值长腿在大中盘中的收益较薄，市值加权头部股票同期表现更好；
4. 没有可用PIT质量数据排除价值陷阱；
5. 正PE过滤排除了亏损公司，但不能替代资产负债表、现金流和盈利质量。

## 5. 执行

主策略：

- 平均持仓50.7只；
- 年化单边换手1.23；
- 累计费用约16,788元；
- 成本后保留89.83%的毛CAGR，略低于90% Gate；
- 整手/买入失败率0.98%；
- 持仓估值缺失率2.06%，略高于2% Gate。

交易摩擦不是失败主因：成本前CAGR也只有2.35%，仍明显落后基准。

## 6. Gate

- CAGR领先1个百分点：FAIL；
- Sharpe领先0.10：FAIL；
- 回撤不显著恶化：PASS；
- 至少两个时期正超额：FAIL；
- 剔除最佳年份仍盈利：PASS；
- 成本保留90%：FAIL；
- 换手：PASS；
- 执行：FAIL（估值缺失2.06%）。

总裁决：**NO-GO**。

## 7. 最终决策

1. 不部署当前EP/BP纯多头价值组合；
2. 不调整EP/BP权重、持仓数或估值阈值继续重搜；
3. 质量路线在获得完整财报公告版本和历史股票覆盖前保持DATA-BLOCKED；
4. 主动选股方向目前只剩低换手MARGINAL候选，没有通过GO的个股策略；
5. 下一步转向股债金多资产配置，目标是可部署的回撤控制和稳定复利，而不是继续寻找个股alpha。
