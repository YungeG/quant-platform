## 1. 目标、模式与范围

**模式：A 股 / Plan；当前为 plan-only。** 本文是工程与研究顺序的规划，不是已冻结、可执行的 `ExperimentSpec`，也不是策略有效性或交易授权。本轮只落规划，不实现新策略、不获取行情、不运行回测。

把五个思路按职责组织，而不是做成必须全部满足的五个串联开关：

```text
P0：冻结定义、范围与样本用途 → 冻结数据及覆盖检查
    ├─ 独立 B 轮次记录：有无 A 提示都记录 → 旧龙头持续性研究
    └─ A→B 提示记录：按事前关系声明产生 → 扩散研究
        两类记录仅关联，不互相作为入样前提
    → 市场背景、旧龙头身份、趋势、波动作为并列属性
        ├─ 提前预警名单：不以 B 已启动或股票已突破为前提
        └─ 趋势确认名单：应用明确的趋势及风险筛选
    → 单层诊断 + 事前声明的少量联合检验（开发样本）
    → 锁定最小候选 → 能力满足后才读取独立保留样本验证
```

第一版交付的是收盘后的观察报告，两类名单均不是买入指令，也不是“综合得分大于某数就买入”。明确区分提供预测信息的假设、描述适用环境的标签和限制风险的条件；五个思路不强制全部进入最终策略。用户已认可的首版候选范围为沪深普通 A 股、日线、只做多，采用申万一级行业；历史分类版本及成员来源仍需P0核验。不混入动态概念板块，不扩展至北交所、ETF、融券或盘中交易。

## 2. 各层职责：不能混用时间尺度

| 层 | 第一版实现 | 暂时不做 |
| --- | --- | --- |
| 牛熊 | 环境标签：复用三指数 MA200、60日动量、连续3日确认；输出 bull/bear/transition/unknown | 不将标签解释为未来涨跌概率；原确认名单的风险门控不等于已证明有效 |
| 地量 | 慢状态标签：复用全市场成交额250日分位、0.80/0.20阈值；主状态保留月末采样及约120日研究尺度 | 不恢复已失败的“地量满仓、其他半仓”；不据此改变短周期名单或仓位 |
| 板块扩散 | 预测假设：对事前固定的少量 A→B 记录源事件、目标、信号时点、失效时点和依据；先只作预警 | 不要求 B 已启动才入样，不扫描后挑最佳关系，不把相关性称因果 |
| 旧龙头 | 个股属性及预测假设：记录目标板块 B 上轮已结束且当时可知的涨幅冠军、并列关系 | 不使用源板块 A 的冠军替代，不把成交量关注名单当冠军，不强制冠军入选 |
| 波动/流动性/趋势 | 在候选池展示指标；趋势确认名单复用现有筛选，另行检验波动下限的选股作用与上限的风险作用 | 不用正动量、突破或高波动预先排除尚未确认的预警对象，不把高波动当正向收益因子 |

牛熊和地量是不同维度，但可能相关，例如“熊市＋地量”可以同时成立；前者描述趋势，后者描述低参与度。不能把它们压成一个相互抵消的分数，也不能假定它们是两份独立证据。其他量价层同样可能重复描述强势行情。

新报告分开保留三类信息：

- **研究事件记录**：分别保留预定义范围内所有合格 B 轮次和 A→B 提示，包括失败信号、被筛除对象及无 A 提示的 B 轮次；不先按牛熊、波动或后续上涨筛样。记录存在不等于结果可评价，统计分母按§7状态规则处理。
- **提前预警名单**：来自 A 的已知信号和事前关系声明，记录 B 当时状态，不要求 B 已启动或股票已突破；只供研究观察，不是提前买入建议。
- **趋势确认名单**：沿用现有观察筛选的 bear 阻止、unknown 无名单、transition 需额外突破行为。此为兼容行为，不代表这些条件已通过收益验证；不能把确认后的表现归功于提前预测。

第一版地量只提供背景，扩散与旧龙头不直接改变现有确认名单或仓位。记录完整不等于证据完整：缺失、迟到和未知状态仍须标未决，不能为保留样本而填零。局部预警可保留独立证据充分的部分，但依赖信息缺失时报告必须显式不完整。

## 3. 先补一份可追溯的最小数据集

优先使用已有本地文件形态和数据准备流程，不新建数据库或服务。

| 输入 | 必要内容与用途 |
| --- | --- |
| 日历与三指数 | 完整开闭市日、收盘、版本和可知时间；复用市场判断 |
| 市场总成交额 | 每日金额、单位、统计范围、应有/实有覆盖及缺失解释；不能用筛选后的股票池求和冒充全 A |
| 板块成员 | 稳定板块身份、逐日有效成员、分类版本、变更生效与可知时间；不以今天成员回填过去 |
| 行业行情 | 与成员及权重口径一致的行业序列；不完整行业不得静默重配剩余权重 |
| 个股行情及身份状态 | 原始 OHLC、可知的复权信号价、成交额、上市退市、ST/停牌状态；保留退市和后续表现差的股票 |
| 板块关系声明 | 明确 A→B、经济理由、预期方向、适用期及声明时点；没有声明就不自动推断关系 |

每份快照保留来源、版本、范围、原始字节指纹及获取时间；逐条区分市场事实发生时间和供应方可用时间。文件下载时间不能倒填历史 `available_at`。本地 SHA-256 不是正式 `MarketBundle` 身份或发布证据。

在完成§6的首读前样本隔离后，先用开发样本中事前指定的板块对及其完整声明成员做小样本冒烟，至少覆盖所有特征暖机和一个完整观察窗口。标记旧龙头身份需要 B 的上轮已结束且当时可知，不要求下一轮已经发生；评价主持续率则需下一轮结束并且冠军结果可知。条件不满足时标未决，不能按结果另挑成功片段。程序异常分支使用合成样本补测。

### 数据覆盖验收

以冻结的逐日成员/上市状态清单生成“声明范围内应有记录”，再与实际输入对账；清单本身也须有范围、版本及可知时间，不能仅从行情文件反推应有成员。

- 分开输出 `input_pool_complete`（已提供记录可用）和 `declared_scope_complete`（声明研究范围的应有记录均有所需数据或权威的合法无交易事实）。沿用旧筛选的 `complete` 只能表达前者，不能证明板块完整。
- 报告应有/实有成员及记录数、缺失标的/日期和原因。整只股票未出现在文件中也必须被发现；行业行情若不完整，不能默默对剩余股票重新配权。
- 已知停牌等合法无交易事实可解释覆盖，但不能伪造价格，也不保证标签可评价。应有交易数据缺失（即使源故障原因已知）、重复/冲突版本、未知归属或迟到记录阻断依赖它们的完整行业结论和冠军判定，局部结果须显式标不完整。
- 全市场成交额的声明范围必须与原研究口径一致，不能用两个板块或行情文件中剩余股票求和冒充全 A；范围变化须另立版本。供应方全局完整性未知时如实披露，局部清单对账不升级为全市场权威证明。
- 同时检查金额单位、日历、除权口径和数据可用时间。缺失不能变成地量、零收益或空机会。

v0.3复核时，`overall/a-share-sw2021-members.csv`、`overall/a-share-2026-sector-volume-panel.csv`、`overall/a-share-volume-diffusion-panel.csv`、`quant_a50.duckdb` 均不存在。这只说明当时这四个既有入口未就绪，不证明其他位置无数据；v0.4未重新探测这些路径或读取项目外旧库。

## 4. 共用因果记录，分开事件时点

统一“板块一轮”的启动、结束确认和冷却定义，但不强迫 A、B 同时启动，也不把不同假设放在同一个事后选定的起点。

### 用户已认可的首版候选定义

候选标识为 `layered_candidate_v1`，理由记录见§7的D01—D17；这是待P0绑定数据及统计细则的研究先验，不是回测最优参数。

`RS5_i(t) = R_i(t-5, t) - R_沪深300(t-5, t)`，使用5个交易日的简单区间收益之差；`MA20`为包含当日的最近20个交易日行业信号序列均值。行业和基准必须使用一致的收益口径，具体序列及历史可知版本在P0绑定，不混用价格指数、全收益指数或ETF价格。

| 项目 | 候选定义 | 时序约束 |
| --- | --- | --- |
| 启动 | 连续2个交易日均满足 `RS5 >= 0.02` 且行业信号收盘 `> MA20` | 第二个确认日的数据实际可知时生成事件，不回填第一天；0.02是2个百分点的收益差 |
| 结束 | 活跃期间连续3个交易日 `RS5 <= 0` | 第三个确认日结束，不回填第一次转弱，也不改成事后最高价日 |
| 冷却 | 确认结束后的10个完整交易日不生成该板块新轮次 | 冷却后重新累计启动确认，不沿用冷却期间的连续满足记录 |
| 缺失 | 中断连续确认并标未决 | 不把缺失当成结束或启动，不跨缺口拼连续天数，不事后追认旧确认 |
| 冠军区间 | 确认启动日收盘至确认结束日收盘的涨幅排名 | 使用该轮冻结参赛集合；并非从事后低点到高点的“市场口头龙头” |

同一规则独立识别A、B各自轮次，但A的预警不要求B先启动。第一轮不额外加成交量放大、财务或资金流条件，也不扫描这些候选参数。参数选择原因与确认滞后的代价必须和结果一起解释。

### 事件单位与关联

- **B 轮次记录**：在事前声明的目标板块范围内独立生成，以“板块身份＋因果启动时点＋规则版本”区分轮次。旧龙头主研究使用所有符合事前资格的 B 轮次，不能只取有 A 提示的子集；有无提示可以是预声明分层。
- **A→B 提示记录**：按“源轮次＋目标板块＋关系版本”识别一次提示，保存 `t_A` 和目标当时状态。每天重算或重复运行不得制造新提示；没有 B 新轮时也保留，不要求先绑定成功的 B 轮次。
- **多对一关联**：多个 A 可以关联同一个 B 轮次，但旧龙头统计中这个 B 轮次仍只算一次。扩散提示按预声明方向分别报告；跨方向汇总时，同一 B 的重叠评价窗口归为同簇，簇内提示等权、合计权重为1，不把提示数当独立样本数。
- 同时报告提示数、唯一 B 轮次数、评价簇数和股票观察数。跨板块的共同市场冲击及相邻时间相关性另按P0冻结的时间块处理；不能按提示行或股票行独立 bootstrap。

这些只是研究记录的逻辑键，不替代 Platform 的 ArtifactRef 或规范身份。

### 时间锚点

| 时点 | 含义与处理 |
| --- | --- |
| `t_A` | A 的启动信号首次可知。此时按事前关系声明冻结目标 B 和预警快照，建立扩散事件，不等待 B 上涨 |
| `t_B` | 独立B轮次的启动信号首次可知，每个真实轮次必有该时点。提示分别关联 `t_A` 时已存在的轮次与窗内后续新轮；后者未发生时关联为空，保留提示但不伪造B轮次 |
| `t_entry` | 未来选定的交易表达满足条件后，实际获准且能够成交的时点。提前预警与确认跟随须分别声明所依赖的信号，不默认为 `t_A` 或 `t_B` 收盘可成交 |

- 启动仅由截至该时点已知的板块相对强度/活跃条件触发；所有触发均保留，不看随后是否大涨。同一轮连续上涨不能切成多个独立事件。
- B 在 `t_A` 已启动、仍未启动及启动证据不足分别记录；已有启动不能算作 A 之后预测到的新启动。B 后续未启动、下跌或反向也保留，不把“等到 B 启动”作为扩散成功样本的入口。
- 旧龙头始终指目标板块 B 的上轮涨幅冠军，只有上轮结束已确认后才能确定；记录 `end_known_at` 和身份可知时点。`t_A` 的快照仅用当时可知的冠军；若确认跟随使用 `t_B` 时的新快照，另行保留，不能倒填 `t_A`。
- 轮次参赛集合按该轮启动时的可知成员冻结，中途退出板块不静默改集合。并列冠军保留，代码排序不制造唯一冠军；前轮并列单列研究组，主持续率使用前轮唯一冠军已知的轮次。冠军未通过当前波动/趋势筛选仍保留身份和排除原因，不能在过滤后的股票中另选冠军。
- 扩散研究控制大盘、风格、B 自身动量和重叠成分造成的解释；旧龙头研究另外与普通近期强势股比较，不将两项结果互相替代。
- 收盘后可知的信息不能计入当天已经发生的可交易收益。没有成交或无法成交时保留原因，不合成成交价或删除事件。

首版主口径见§7：扩散评价 `t_A` 后5个交易日的市场相对收益增量；旧龙头主评价整轮再次第1，`t_B` 后20日排名仅为辅助诊断；地量保留月末状态和旧120日证据。自然轮次尚未结束时，不能用20日结果代替整轮结果。P0须把候选轮次规则、精确收益起止Bar、最长观察/行政截止及模型训练规则绑定为正式声明，不能拼接不同起点的收益，也不能把诊断期限自动当交易持有期。

扩散提示按预定时点过期，不续期等待上涨；过期后 B 才启动，不能追认“窗口内启动”成功。窗口内启动和绝对上涨率是辅助结果，不能替代扩散的主收益增量指标；没有启动但价格齐备时，其5日收益仍须评价。地量的半年证据不能直接作为5日或20日机会有效的依据。

## 5. 最小代码落点与兼容性

| 已有入口 | 处理方式 |
| --- | --- |
| [`evaluate_market_regime`](../experiments/a_share_market_regime.py) | 原规则、输入时间语义和失败处理不变 |

| [`rolling_volume_scores`](../experiments/run_ground_volume_validation.py) | 复用纯分位计算及原并列口径；不复用旧脚本的联网、PnL或未经覆盖核验的聚合路径 |
| [`run_a_share_market_regime`](../experiments/run_a_share_market_regime.py) | 保持现有参数和输出兼容；新组合报告使用独立入口，或显式选择新版本，不能静默改变旧结果 |

真正需要新增的计算集中在板块事件、关系提示、历史冠军的一个小型纯计算模块；接收冻结输入和显式 as-of，返回结果与原因，不联网、不读系统当前时间、不下单。独立 B 轮次和 A→B 提示分别生成，再按时点关联；研究事件和提前预警读取声明范围的输入，不依赖趋势确认名单。覆盖对账必须使用外部冻结成员清单，不能从 watchlist 推导完整性。只在有真实第二调用点时提取共享读取/计算函数，不先搭插件框架。

地量月末状态有一处必须单独处理：旧 `month_end_indices()` 将输入最后一行视作月末，不能直接用于任意 as-of 的当前月。新报告应通过权威交易日历判断已经完成的月末，输出状态所属月份与年龄；最新日分位若展示，标明只是日度诊断。不能把月中最后一条记录当完整月末。

新报告至少包含：as-of/决策日、规则和数据版本、样本用途、市场/地量标签及所属时点、独立 B 轮次和关联提示、`t_A`/`t_B`及提示到期时间、冠军可知时点、候选池指标、分开的预警/确认名单、被筛除原因、两种完整性及覆盖对账。研究报告另列结果状态、分母、未决占比和评价簇数。`t_entry` 仅由未来的执行验证记录，诊断不虚构成交。数据错误、证据不足、合法空名单分别表达；局部结果不等于完整报告。

## 6. 实施顺序与交付门槛

| 阶段 | 工作与交付 | 验收/停止条件 |
| --- | --- | --- |
| P0 数据与定义 | 元数据覆盖核查、首读前样本隔离、事件及主标签定义、有限检验集合和验收门槛 | 未填齐§7冻结字段不得进入对应统计；无历史成员/可知时间则阻断依赖结论，不伪造快照或未见样本 |

### 首读前样本使用顺序

1. **P0先隔离**：先核查元数据和已消费记录，冻结开发/保留区间、数据版本与用途；未完成时只可做元数据核查和合成输入测试。真实行情冒烟使用开发区间的独立切片，不提供含保留区间的全历史CSV后再过滤；`as_of`约束不能撤销已经发生的样本读取。
2. **开发样本**：P1/P2真实冒烟、P3单项/联合研究和P4选择均记为开发消费。P3看过收益后在同一历史上评价P4是允许的开发工作，不是新增独立证据；时间折结果也不能自动叫未见样本外。
3. **候选锁定**：在任何保留样本读取前，锁定策略/规则版本、完整参数与交易表达、选择规则、指标和验收门槛。没有合格候选就不选，不通过观察保留期挑赢家。
4. **保留样本**：只有资格核验、公开执行能力和正式消费预留均满足后才能读取；正式流程由现有 `SampleConsumptionLedger` 在相应读取前完成预留，失败则不读。候选特定 ValidationPlan 按平台协议冻结，不自行另建消费或证据系统。
5. **不能洗白已见历史**：换算法、文件名或数据修订不使已观察行情重新成为未见证据。既有[吸收扩散研究](a-share-turnover-absorption-conclusion.md)已观察2025及部分2026结果；逐段核查而非假定整年可用。没有可信未读历史就保留未来独立窗口，当前结果只称历史开发/再检验。

H-D采用固定小型线性模型：基线M0包含截距、B近5日相对收益、沪深300近5日收益、中证1000相对沪深300的近5日表现；M1仅额外加入对应A的当日启动指示。不搜索其他特征、交互或非线性模型，暂不采用匹配法。对照池必须同时含信号和无信号日期，否则启动指示无法比较；A资料不足的日期是未决，不能编码成无信号对照。按时间顺序，仅用当时已成熟的标签拟合；训练窗、更新频率、最少训练信号及 `Δ_D` 的具体估计式在P0冻结，不能用拟合优度或方向准确率替代主收益增量。

市场调整和拟合只使用当时可知或更早训练信息；简单减去沪深300不等于排除了全部beta/风格因素，小盘相对表现也不是完整风格模型。H-L的轮次区间、收益口径及候选集合须冻结：前轮并列单列；下一轮并列第1算进入第1名集合，同时单列并列比例，不称唯一冠军。即使 `p_repeat` 达标，也不能据此声称优于普通动量，该增量须达到另行预声明的比较门槛。

首版候选验收数值如下，理由和代价见D11—D15：

- H-D最小值得关注效应为5日增量 **0.5个百分点**（`0.005`）；H-V为20日增量 **1个百分点**（`0.01`）。它们是研究重要性门槛，不是费用推导出的盈亏平衡点。
- H-L强命题门槛为 `p_repeat > 0.50`。强命题失败后，不能用“保持前列”或仅超过随机概率改判通过。
- H-D/H-L/H-V等事件型主检验至少有 **50个成熟、可评价且按相关性处理的轮次或事件簇**；不以提示行数、股票行数或交易次数代替，达到50仍不保证检验功效。H-R/H-C的经济样本充分性须按其冻结表达另定，不能用50次交易替代。
- 未知结果比例候选上限 **5%**；分母是原合格事件/簇，右删失和数据未决按单位去重计入未知。不得删掉未知样本后再算比例，5%以内也仍须满足下述缺失边界及敏感性要求。
- **整体95%置信水平**：指预声明主检验集合的整体控制，不是每项各做一个95%区间就视作整体95%。相关性处理、时间块、校正方法及具体计算尚需P0冻结。

P0仍必须登记数据范围/版本、事件资格、精确收益Bar及成熟时点、对照模型训练和效应估计规则、主检验集合、区间方法/时间块/多重比较处理、非负seed和计算预算。H-R允许收益代价、H-C具体方案及其门槛也未确定。不完整字段不视为默认值，相关项仍为 `NOT_READY`。

研究层“保留/不支持/未决”按同一原则执行：满足数据、样本和未决比例要求后，经预声明相关性/多重比较处理的区间下界必须严格超过最小效应，才可保留；即H-D须超过0.005、H-V超过0.01、H-L超过0.50，而非仅点估计达标。上界不超过门槛则不支持该强度的主张；区间跨门槛或证据不足则未决。风险项还需满足预定收益代价约束，辅助指标不得替换主指标；这些不是正式 `ValidationReport`。

### 后续结果与修改如何追溯

每次研究至少关联：`candidate_version`、受检验的决策ID、规则/代码版本、数据版本与区间、开发/保留用途、覆盖及S/F/U或连续标签分母、主效应与区间、辅助诊断、结论和证据位置。区分**观察事实**与**原因假设**：例如“事件少”是事实，“冷却过长导致”尚需证据，不能仅凭不满意的结果认定参数错了。

- 诊断优先级：数据/实现错误 → 口径和时点 → 样本与缺失 → 普通动量/市场替代解释 → 主假设是否成立。诊断不授权读取保留样本调规则。
- 本表保留为 `layered_candidate_v1` 的原始决策记录。后续变更追加新候选版本及“旧值→新值、理由、已见结果、影响范围、重新验证要求”，不就地改旧值或倒改当时理由；旧失败/未决结果继续保留。

| 完整窗口、价格齐备，B未启动 | H-D的5日收益照常评价；仅对辅助“窗口内启动”指标算失败，不统一填零收益 |
| 样本截止时窗口/自然轮次未走完 | 右删失；保留事件及资格，结果未知，不当失败或成功，不用短窗口补主标签 |
| 行情、身份或结束确认缺失 | 数据未决，列出原因与数量；不因后续表现差改变原入样资格 |
| 上轮冠军在本轮开始时已确知退市或不在B参赛集合 | H-L“本轮再次冠军”计否，仍保留该轮；若身份/成员事实未知则未决，不推测 |
| 本轮中途退出板块、停牌或退市 | 不改已冻结参赛集合；有可核验结果按冻结口径评价，缺终止回报等证据则未决，不以最后报价补结果 |
| 信号成立但无法成交 | 单列执行状态；预测标签可在数据齐备时评价，执行收益及现金处理由Backtest决定，不删除失败尝试 |
| 前轮并列或无足够历史确认前轮 | 单列资格组及数量，不伪造唯一冠军；不能纳入主持续率后再因结果不利而排除 |

每项报告总事件数、事前合格数、已评价成功/失败或连续指标样本数、右删失数、数据未决数、不可执行数及其交叉关系；执行状态与预测结果可能重叠，不强行凑成互斥的一列。

H-L在固定合格分母中，已知成功为 `S`、已知失败为 `F`、未知结果为 `U`，按唯一B轮次计数且 `N=S+F+U`；多种未决原因不能重复增加 `U`。必须同时报告识别范围 `[S/N, (S+U)/N]`及处理相关性后的不确定性；`N=0`为未决。仅完整样本胜率不得作为通过依据。连续收益没有可辩护缺失边界时，关键缺失阻断主结论，不只凭完整样本均值通过；停牌/退市等非随机缺失须单列敏感性检查。

量价层可能相关，五层不是五份独立证据。所有方向、期限、市场子组及联合方案计入预声明检验集合，按事件簇和时间相关性处理区间估计；事后产生的新解释另立假设与验证样本，不回填为本轮通过。

## 8. 交易表达：独立声明，在评价交易表现前冻结

P3 的预测信息与条件作用不等于可交易收益。不在这一轮凭空指定仓位比例或最优止损；进入 P4 时、观察组合交易表现之前，必须固定选择“提前参与”还是“确认跟随”，若两者均测则列为两个预声明方案，不混用其入场时点。还须写清：

- 实际标的范围、固定候选排序/并列处理、最大持股数、单股及行业上限；
- 入场的下一可成交时点、持有期、换仓和退出、冲突信号优先级；
- 数据失效时禁止新建仓与已有持仓处置分别定义，不假定能立刻平仓；
- T+1、整手数量、涨跌停无法成交、停牌、退市、公司行动以及真实成交价；
- 选定账户/交易路径与产品类别的历史费用、最低佣金、卖出税费和成本压力情景。

扣成本后的组合应与同市场/行业暴露、同平均仓位的简单基线比较，不以长期少持股票造成的回撤下降冒充择时优势。成交、账户、费用、PnL和结果等级仍由 Backtest 独占，不新建模拟器。

### 研究、Backtest与正式Validation的指标映射

v0.3也复核了公开 `crypto_quant_validation.OosRule`；截至该轮，其[实现](../strategy-validation/src/crypto_quant_validation/integration.py)只接受 `simple_period_return`、单位 `fraction`、操作符 `gte`，并要求满足声明的 `minimum_trade_count`。最低交易数不是独立事件数要求，绝对区间收益阈值也不是相对基线或风险改善检验。

| 要检验的条件 | 结果归属 | 当前能否直接作为正式OOS规则 |
| --- | --- | --- |
| H-D收益增量、H-L冠军持续率、H-V选股差异、事件区间/分母 | 描述性研究及其输入/方法记录，不是成交或组合PnL | 不能；不得包装为正式 `supported` |
| 净收益、回撤、费用、成交与组合路径 | Backtest的已验证完成发布及其受支持分析；具体metric profile须另行确认 | `OosRule`不能直接表达回撤改善或相对基线差值；不能自行计算后注入报告 |
| `simple_period_return >= threshold`，且交易数达到下限 | 当前受支持的正式OOS条件之一，仍需全部来源/样本/等级等条件满足 | 可以表达该有限条件，但不代表本策略全部研究和风险门槛通过 |
| 完整H-R/H-C收益—风险目标 | 须逐条绑定受支持的公开分析与Validation契约 | 当前映射未闭合，P5不放行完整策略验证 |

P5有两个独立阻断：本多股票A股的公开preparation/profile未确认，以及完整验收条件无法由当前OOS规则表达。前一项同时阻断P4的经济回测，不是等到P5才检查；H-R等组合经济指标不得在P3自算PnL替代。后续可将不支持项诚实保留为研究结论，或另立经过批准的公开契约扩展任务；不能降格检验目标后仍声称原目标通过。本计划不实现平台扩展，不使用私有调用或第二套PnL绕过。

执行前还须补齐并冻结：

1. dataset revision、声明成员清单、真实开发/保留样本边界及规范半开区间 `[start, end)`；
2. §7逐项冻结表、具体板块对、事件/关系版本、阈值/冷却/期限、结果状态与统计权重，以及显式、有限、可排序的方案和参数组合；
3. 非负 seeds、scenario refs、strategy/template 与 metric profile refs、grade、执行预算；
4. 事前 `SelectionPolicy`，只从合格已完成结果中确定性选择，无合格者不选；
5. 经消费核查的 holdout、首读前预留安排、兼容实际能力的 `ValidationPolicy`及完整目标的指标映射。

这些字段或公开能力缺失意味着目前不能宣称完整实验计划已经冻结。数据准备、规则工具和描述性研究可分阶段推进，不等于正式 Backtest 或完整策略Validation能力已经具备。
