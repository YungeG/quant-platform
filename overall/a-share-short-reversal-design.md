# A股流动性约束短期反转预注册设计

- **状态：** frozen before execution
- **目标：** 验证A股短期反转能否在纯多头、月频、可执行大中盘股票中提供高于基准的主动收益
- **窗口：** 2016-01-01—2026-08-25

## 1. PIT股票池

每20个交易日：

1. 上市至少252个交易日；
2. 当日未停牌，收盘至少5元；
3. 过去20日平均成交额前50%；
4. PIT流通市值最大的500只；
5. 过去5日没有一字跌停；
6. 过去20日跌幅不低于-30%，避免把重大事件/濒危股票当普通反转。

## 2. 信号

- `ret20 = adj_close / adj_close[-20] - 1`；
- 按日MAD去极值、申万一级行业和对数流通市值中性化；
- 中性化后过去20日收益越低，反转分数越高；
- 主策略选30只，诊断组合选50只；
- 不做空赢家，不搜索窗口、持有期或选择数量。

## 3. 执行

- T日收盘决策，T+1开盘执行；
- 每20个交易日更新目标；
- 仍在目标集合的股票不强制再平衡；
- 掉出集合全部卖出，新股票按NAV/目标数购买；
- 100股整手；买入13bp、卖出18bp；
- 一字涨停买入最多重试3日，一字跌停卖出持续顺延。

## 4. 基准和固定时期

基准：同一PIT Top-500股票池的季度/20日更新市值加权与等权代理。

固定时期：

- 2016—2019
- 2020—2022
- 2023—2026

## 5. GO Gate

主策略Top-30全部满足：

1. 净CAGR至少高于Top-500市值基准1个百分点；
2. Sharpe至少高于基准0.10；
3. 最大回撤 <= 35%；
4. 三个固定时期至少两个净超额CAGR > 0；
5. 剔除最佳年份后CAGR > 0；
6. 成本后保留至少80%的成本前CAGR；
7. 年化单边换手 <= 4.0；
8. 平均持仓至少25只，执行失败率<=10%，估值缺失率<=2%。

CAGR为正且有部分超额但未全通过时为MARGINAL；净CAGR<=0或相对基准无增量时为NO-GO。
