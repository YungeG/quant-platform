# 股债金更高收益目标预注册设计

- **状态：** frozen before execution
- **用户目标默认化：** 争取长期CAGR至少10%，同时最大回撤不超过20%
- **基础策略：** 已通过验证的三资产1/N和固定30/50/20
- **窗口：** 2017-01-03—2026-08-25

## 1. 冻结候选

1. `equal_1n`：不加杠杆基准。
2. `equal_1n_1.25x`：三资产各41.67%，总风险资产125%。
3. `equal_1n_1.50x`：三资产各50%，总风险资产150%。
4. `fixed_30_50_20_1.50x`：股票45%、国债75%、黄金30%，总风险资产150%。
5. `equal_1n_vol12`：用过去252日组合波动率将三资产1/N目标调整至12%年化波动，杠杆限制在0.75—1.50倍。

不测试超过1.5倍杠杆，不使用收益预测、宏观择时或资产权重扫描。

## 2. 成本与融资

- 季度调仓，T日收盘形成目标，T+1开盘执行；
- ETF单边交易成本8bp；
- 超过100%的资产名义由负现金融资；
- 基准融资成本5%年化，按交易日逐日计提；
- 另报告7%年化融资成本压力情景；
- 不假设融资利息可税前抵扣；
- 40万元账户、100份整手可行性单列。

## 3. 固定时期和压力年

- 2017—2019
- 2020—2022
- 2023—2026

压力年：2018、2022。报告CAGR、Sharpe、最大回撤、年度收益、年化换手、平均/最大杠杆、交易成本和融资成本。

## 4. GO Gate

候选全部满足才为GO：

1. 基准5%融资成本下CAGR >= 10%；
2. Sharpe >= 0.80；
3. 最大回撤 <= 20%；
4. 三个固定时期CAGR全部为正；
5. 2018和2022单年亏损均不超过15%；
6. 7%融资成本压力下CAGR >= 8%，最大回撤 <= 22%；
7. 最大杠杆 <= 1.50；
8. ETF单边交易成本后保留至少97%的成本前CAGR；
9. 所有非零目标均满足40万元账户100份整手可行性。

CAGR介于8%—10%且回撤合格时为MARGINAL；CAGR<8%或回撤>25%时为NO-GO。

## 5. 复杂度原则

若固定1.25x或1.50x已通过，不保留波动率目标，除非`equal_1n_vol12`的Sharpe高至少0.05或最大回撤改善至少3个百分点且CAGR少不超过1个百分点。

## 6. 边界

- 这是杠杆配置研究，不是无风险提高收益；
- 实盘前必须确认券商融资标的、担保比例、利率、追加保证金和强平规则；
- 本轮不模拟券商级强平，因此即使GO也只能进入shadow/实施审计阶段。
