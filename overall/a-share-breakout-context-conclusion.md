# 突破回踩上下文特征结论

- **总裁决：MARGINAL**
- **基础样本：** 205个可执行事件，203个具有完整20日结果
- **增强账本：** `overall/a-share-breakout-context-events.csv`

## 2. 最强发现：获利盘拥挤

`winner_rate`与后续收益在三个固定时期均为负相关：

- 2016—2019：-0.195；
- 2020—2022：-0.239；
- 2023—2026：-0.110。

成功事件winner_rate中位数86.2%，失败事件90.81%。未校正p=0.021、bootstrap区间不跨0，但五项Holm校正后p=0.105，不能宣称正式通过。

仅作机制诊断的五分位显示：最高获利盘组（约96%以上）20日active均值-3.90%、中位数-3.67%；63%—84%组均值+2.23%。这些边界由本样本产生，不能回填为交易阈值。

核心解释：突破回踩时若几乎所有历史筹码都已获利，恢复上涨会面对更强止盈供给；价格高于平均成本本身没有信息，真正有信息的是获利筹码比例。

## 3. 资金流

冻结主检验`moneyflow_ths`只有18个事件，无法判断。

独立来源诊断`moneyflow_dc`覆盖41个2024年以来事件：

- 总体rho=+0.327，p=0.037；
- 2024 rho=+0.508；
- 2025—2026 rho=+0.551。

方向较强，但它不是本轮五项主检验，且样本短，不能事后升级为通过项。应作为前向确认特征持续记录。

## 4. 无效或不足的信息

- 近5日是否涨停/炸板几乎没有单调信息；
- 游资数据仅1个事件有非零记录，不能用于统计，且观察方向与预期相反；
- 分析师EPS修正对突破回踩只有弱正相关，早期时期方向为负；该数据可能更适合独立的盈利修正策略，而不是技术回踩过滤器；
- 同花顺资金流历史主要从2025开始，当前不足以跨周期验证。

## 5. 决策

1. 不修改突破回踩V2形态；
2. 前向Shadow每日记录`winner_rate`，检验其负向单调关系；
3. 前向记录东方财富`net_amount_rate`，但不设置阈值；
4. `report_rc`转入独立分析师修正研究，不继续作为回踩过滤器调参；
5. 暂停涨停次数和游资特征路线；
6. 若筹码与资金流前向继续有效，再决定是否采购分钟/竞价数据。

**当前最有价值的上下文信息是：低获利盘拥挤＋正资金流确认。证据有方向但未达到部署标准。**
