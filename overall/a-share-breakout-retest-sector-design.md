# 突破回踩板块效应预注册设计

- **状态：** frozen before execution
- **基础事件：** 已冻结的4,447个突破回踩V2事件，不重新识别或修改形态阈值
- **目标：** 判断突破发生时的行业领导力能否区分成功和失败回踩

## 1. PIT板块特征

在每个突破日记录申万一级行业：

1. 行业20日、60日收益；
2. 行业60日收益在30个一级行业中的百分位；
3. 行业指数是否位于MA60上方；
4. 行业内历史成员站上各自MA20的比例；
5. 个股60日收益减行业60日收益。

所有特征只使用突破日及之前数据。

## 2. 冻结板块确认条件

`sector_confirmed`同时满足：

- 行业60日收益百分位 >= 70%；
- 行业指数收盘 > MA60；
- 行业成员MA20宽度 >= 55%；
- 个股60日收益高于所属行业。

不扫描Top-20/30/40%、MA窗口或宽度阈值。

## 3. 验证

在原执行事件中比较sector-confirmed子集与全部事件：

- 5/10/20日成本后active；
- 中位数、胜率、bootstrap区间；
- 三个固定时期；
- 结构失败原因在领先/非领先行业的分布。

## 4. GO Gate

sector-confirmed执行事件全部满足：

1. 数量>=80；
2. 20日平均active>=1%；
3. 20日中位数>0；
4. 20日胜率>52%；
5. 三个固定时期至少两个平均active>0；
6. bootstrap 95%下界>0；
7. 相对全部事件，20日平均active提升至少1个百分点或胜率提升至少5个百分点。

均值改善但样本或稳健性不足为MARGINAL；均值不改善为NO-GO。

## 5. 边界

板块效应只作形态条件，不建设行业轮动策略。原事件和失败原因保持不变，新增字段写回独立增强账本。
