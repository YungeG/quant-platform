# A股业绩预告漂移预注册设计

- **状态：** frozen before execution
- **目标：** 验证管理层首次正面业绩预告后是否存在可交易的20/60日价格漂移
- **窗口：** 2016-01-01—2026-08-25

## 1. 事件

主事件：`forecast_vip`首次公告，满足：

- `ann_date == first_ann_date`；
- 预告类型为`预增`或`扭亏`；
- 报告期、证券代码、公告日完整；
- 保留首次行，不用后续修订覆盖；
- `预增`与`扭亏`分别报告，合并样本为主Gate。

不使用分析师数据，不将后续正式财报倒填至预告日。

## 2. PIT股票池

公告日股票必须：

- 上市至少252个交易日；
- 当日未停牌、价格至少5元；
- 过去20日平均成交额前50%；
- PIT流通市值前50%；
- 非一字涨停开盘可买。

## 3. Event study

- T日公告，T+1开盘进入；
- 持有20或60个交易日，以相应未来开盘退出；
- 事件收益减同日PIT可交易股票池等权未来收益；
- 扣除31bp往返成本；
- 同一股票同一报告期只使用首次公告；
- 报告均值、中位数、胜率、bootstrap置信区间、固定时期和公告类型。

## 4. 月度可交易组合

- 每月最后一个交易日，汇总当月已公告且当时可交易的`预增/扭亏`事件；
- 若超过20只，按预告净利润同比区间中点从高到低取20只；缺少区间的事件排在末尾；
- 下一交易日开盘买入，持有至下月调仓；
- 等权，新进入买入、退出集合卖出；
- T+1、100股整手、涨跌停延迟、买入13bp/卖出18bp；
- 对照为PIT大中盘高流动性股票池市值加权代理。

## 5. Gate

### Event Gate

合并事件全部满足：

1. 成本后20日平均active return >= 1%；
2. 成本后60日平均active return >= 1.5%；
3. 三个时期至少两个20日active return > 0；
4. 20日active胜率 > 52%；
5. 不可买事件比例 <= 10%。

### Portfolio GO

Event Gate通过后，月度组合还须：

- CAGR至少高于基准1个百分点；
- Sharpe至少高于基准0.10；
- 最大回撤 <= 35%；
- 三个固定时期至少两个正超额；
- 剔除最佳年份后CAGR > 0；
- 成本后保留至少80%的成本前CAGR；
- 年化单边换手 <= 4.0；
- 执行失败和估值缺失均<=10%/2%。

Event Gate失败即总策略NO-GO，不通过月度组合结果补救。
