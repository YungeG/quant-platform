# A股真突破股票篮子V8设计（预注册）

## 不变项

沿用V5 `TRUE_BREAKOUT_CONFIRMED`：D0双10日突破，D1—D10守住两条突破位，D10行业收益>=7%、相对收益>=3%。D10收盘确认，D11开盘执行，主期限10日、稳健期限20日。

## 唯一变化：执行载体

确认日按PIT申万一级成员和可交易状态：

- 剔除ST、停牌、上市不足252日、价格<5元、成交量为0和流通市值缺失；
- 按过去20日平均成交额降序选择前10只；
- 至少5只才形成有效事件；
- 等权、40万元事件资金、100股整手；
- D11开盘买入，遵守涨跌停与一次买入重试；
- 固定10日/20日收盘评价；买卖各15.5bp，总成本31bp。

不按历史收益、价格强度、分析师修正、质量或个股事件选股。

## Event Gate

- 完整10日事件>=50；
- 10日绝对正收益率>=60%、跑赢率>=60%；
- `return10>0且active10>0`>=55%；
- return10中位数>=2%、active10中位数>=2%；
- active20中位数>0；
- active10 bootstrap 95%下界>0；
- 去除最佳5%后active10均值>0；
- 2018—2022、2023—2024、2025三个时期active10均值均>0；
- 2025至少8个事件、成功率>=50%、active10中位数>0。

通过Event Gate后才允许冻结重叠信号的账户级组合规则；未通过则不搜索Top-5/Top-20、持有期或额外选股因子。
