# 卓创资讯价格中心导出权限门槛研究

> 归档说明（2026-09-22，非重新检索日期）：下文保留原调研记录；产品、资费、准入、接口和许可条件未在本次联网复核，未注明日期的断言不能当作现行报价或已获权限。URL 仅作原始来源定位，实际采购或接入前须重新核对一手条款并取得相应批准。本次只归档，不发送询价、不开户、不采集数据，也不授予交易或再分发权。

**范围与结论（2026-09-02 检索）**：公开的卓创一手页面说明价格中心可展示实时/收盘价格，并宣传“下载一年历史收盘数据”；但没有公布将该下载/导出能力对应到任何明确的产品等级、订阅费率、数据中心套餐、订单、账户字段或 `PowerType` 数值的权限矩阵。因此，不能从公开资料认定“购买某一层级”或“已有某订单”必然获得丙烷曲线导出；应由卓创客户经理按当前合同/SKU 和账户逐项确认并开通（如可开通）。

## Publicly documented facts

1. **价格中心的公开产品描述同时提到浏览、在线加工与一年历史下载。** 卓创数据中心页将价格中心描述为按品目展示实时价格、收盘价格，可“展示、下载一年历史收盘数据”，并支持在线查询与加工分析；列出的数据类型包括市场价格、企业价格、国际价格、期货价格。该文案说明这些是价格中心的公开能力描述，但没有说明每项能力适用于哪些订阅或账户。\
   来源：[卓创数据中心—专业数据，触手可及](https://digital.sci99.com/channel/datacenter)

2. **丙烷是价格中心公开可访问的单品页面，且该站区分市场价格和企业报价。** 丙烷页面属于 `prices.sci99.com` 的价格中心产品页；价格中心的公开说明将市场评估价格与企业报价区分，并说明市场价格/收盘价格的形成和更新规则。这证明“丙烷曲线可看”属于价格中心展示场景，不能证明下载权自动随查看权赋予。\
   来源：[丙烷价格中心页](https://prices.sci99.com/cn/product.aspx?ppid=12513&ppname=%25u4e19%25u70f7)；[价格中心主页](https://prices.sci99.com/cn/)

3. **卓创公开提供多种、彼此独立描述的数据交付产品。** 数据超市被描述为可按最小颗粒数据项 7×24 自主选购，且包含价格数据；价格中心则是组合展示/查询/加工产品。页面没有说数据超市购买自动授予价格中心导出，也没有说价格中心订阅自动包含数据超市数据。\
   来源：[卓创数据中心—专业数据，触手可及](https://digital.sci99.com/channel/datacenter)

4. **Excel 批量导出被明确宣传为“红桃3”终端及其 Excel 插件的能力。** 红桃3页面称其数据中心支持下载导出，Excel 插件可与软件数据库、收藏数据/模板同步，实现价格和基本面数据的批量快速导出。该页面描述的是红桃3产品，不能把它当作普通价格中心网页导出的公开许可条款。\
   来源：[红桃3大宗商品决策终端](https://www.sci99.com/subject/diagram/down/)

5. **API/系统集成被公开描述为数据定制服务。** 卓创把“数据集成”称为数据定制项目，通过 API 接口为客户提供数据服务，以满足 CRM、SRM、ERP 等系统对第三方数据的需要。公开页没有给出价格中心网页权限与 API 权限之间的包含关系、费率或自动转换规则。\
   来源：[卓创数据定制—数据加工，按需定制](https://digital.sci99.com/channel/customized)；[卓创资讯官网服务介绍](https://corp.sci99.com/)

6. **公开路径是客户经理/官方热线，而非自助权限说明。** 数据中心页面提示登录后查询客户经理联系方式，或致电 `400-811-5599`；这支持向客户经理核实当前服务，而不是根据前端字段自行变更权限。\
   来源：[卓创数据中心—专业数据，触手可及](https://digital.sci99.com/channel/datacenter)

## What public sources do NOT specify

公开官方资料**没有发布**以下信息；本研究不能补推：

- 价格中心 Excel/CSV 导出是否必须购买某个名称固定的产品层级、付费订阅、行业包、数据中心包或数据超市数据项。
- 导出与“可查看单条/单曲线”是否同一授权，或是否另有按品目、曲线、区域、历史区间、用户席位或次数的限制。
- 一年历史“下载”是网页导出、文件下载、Excel 插件下载、API 交付，还是这些方式的任一组合；以及每种方式的格式、频率、行数/历史范围和许可用途。
- `PowerType` 的公开定义、枚举表、后端权威性，及其与合同 SKU、付费状态、订单号、用户/企业账户标记或客户经理操作的映射。
- 是否存在可公开购买的价格表、最低消费、采购订单前置条件、开通 SLA，或“已购买但需客户经理激活”的标准流程。
- 红桃3、数据超市、产业数据包或 API 服务是否能够、或是否需要，替代当前价格中心网页的丙烷导出权限。

换言之，**未发现公开发布的价格或权限门槛**。不能因为页面宣传“下载一年历史收盘数据”，就断定当前任意可查看账户都应能导出，也不能断定必须升级到红桃3、购买数据超市或 API。

## Interpretation of PowerType 2 vs 1

> **Implementation observation, not a vendor contract or entitlement definition:** current session view-only PowerType 2, native export code checks equality to 1.

这一观察能可靠说明：在所观察到的当前网页实现路径中，查看丙烷单曲线与该原生导出分支并非同一前端条件，且当前会话没有通过该导出条件。它**不能**证明 `2` 的官方业务名称是“查看版”、`1` 是“付费版/导出版”，也不能证明任一数值对应特定套餐、订单、账户级 flag 或客户经理权限。

不要篡改脚本、请求、浏览器存储或服务端参数以绕过该检查。即使前端条件可见，服务端授权、合同的数据使用范围及审计责任仍以卓创的正式确认和实际授权为准。

## Smallest request to account manager

向当前客户经理或官方热线发送以下最小请求（无需提供密码、Cookie、截图或账户标识给非官方渠道）：

> 我们的价格中心账户可查看“丙烷”单曲线，但网页原生导出未获授权。请核对当前合同/订购项及该登录用户的价格中心权限：是否包含**丙烷价格中心收盘历史的网页 Excel/CSV 导出（请明确历史范围）**？若不包含，请给出最小可购买或可在现有合同下开通的 SKU/增购项、费用、席位/用户范围、生效时间和书面许可范围；如需账户级开关，请仅在合同允许时为指定用户开通并书面确认。我们不需要 API，除非网页导出无法合法满足需求。

这先请求对**单一品目 + 单一交付方式 + 所需历史范围**的书面确认，避免无证据地升级到更大产品包。

## Exact procurement questions

要求客户经理/采购对以下问题逐项、书面答复：

1. 当前合同、订单或订购 SKU 中，哪些项目授予价格中心丙烷的**查看**权？哪些项目授予**网页 Excel/CSV 导出**权？
2. 对丙烷，网页导出可取得的是实时、收盘、市场价格、企业报价中的哪些数据？具体区域/规格/曲线有哪些边界？
3. 网页导出的最大历史范围是否为一年？“下载一年历史收盘数据”是否为本账户当前适用权利，而非通用宣传？
4. 导出是否按企业账户、登录用户、席位、IP、品目、数据项、时间段、导出次数或文件行数限制？请提供限制和计量口径。
5. 导出权是否必须另购价格中心、数据超市数据项、产业数据包、红桃3，或其他 SKU？若是，请逐项说明不可替代关系，不接受仅给产品名称的答复。
6. 是否有现有合同中的未激活授权、待绑定用户席位或待执行订单？若有，开通所需的合同依据、审批人和 SLA 是什么？
7. 客户经理是否能对指定用户设置账户级导出开关？该开关的正式名称、审计记录、有效期和撤销条件是什么？
8. 价格中心网页导出、红桃3/Excel 插件批量导出、数据超市文件/数据交付、API 接口是否分别授权？请提供每种方式的可用性和许可范围。
9. 若改用 API：是否另需数据集成合同、接口文档、认证凭据、调用/并发/历史范围限制和再分发限制？报价是一次性、订阅还是按量？
10. 所导出数据可否用于内部分析、自动化入库、内部共享、对外报告或再分发？请引用合同条款或授权文件。
11. 请给出最小满足“丙烷、所需历史收盘曲线、单用户网页导出”的方案总价、税费、合同期限、续费、开通日期和退订/变更条件。
12. 开通后请提供可复现的验证步骤和书面回执；若不能开通，请明确拒绝原因是产品范围、账户范围、订单状态还是系统限制。

## Decision and next safe action

**决定：不采购、不改客户端、不尝试绕过。** 当前证据足以认定：浏览丙烷曲线不等于已被证明拥有原生导出许可；但不足以认定任何特定产品、付款、订单或账户开关就是门槛。公开资料只说明产品能力和存在数据交付/客户经理路径，未公布权限映射或价格。

**下一安全动作：** 将“Smallest request to account manager”发送给卓创当前客户经理，或使用公开官方热线 `400-811-5599`，索取书面 SKU/合同—权限映射和最小方案报价。收到书面答复后，只验证卓创正式开通的原生导出；若业务实际需要 API，再走独立数据集成采购评估。

## Research gaps

- 卓创未在所检索的公开官方页面发布价格中心导出权的 SKU、定价或权限矩阵。
- 未取得当前账户的合同、订单、管理员配置或客户经理书面说明；本研究不访问这些受限资料，也不修改任何会话或 Windows VM。
