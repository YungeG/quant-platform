# 突破回踩板块内聚集效应预注册设计

- **状态：** frozen before execution
- **基础事件：** 原4,447个突破回踩事件，不修改形态定义
- **目标：** 使用细分行业内同期突破聚集，而不是整个申万一级行业，识别有共同催化的突破

## 1. PIT同伴组

- 优先使用突破日所属申万三级行业，PIT成员数至少5只；
- 三级行业不足5只时，回退至申万二级行业，PIT成员数至少8只；
- 无合格同伴组记为`peer_group_unavailable`。

## 2. 聚集特征

在突破日收盘可见范围内记录：

- 最近5个交易日同伴组内其他股票的突破事件数量；
- 突破股票数/PIT同伴组成员数；
- 同伴组指数20日收益；
- 同伴组指数是否位于MA20上方；
- 使用L3还是L2及成员数量。

当前股票不计入peer breakout count；同日其他股票可计入，因为均在收盘后决策。

## 3. 冻结聚集确认

`cluster_confirmed`同时满足：

- 其他同伴突破数>=2；
- 5日突破密度>=10%；
- 细分行业指数20日收益>0；
- 细分行业指数收盘>MA20。

不扫描同伴数量、密度、窗口或L2/L3阈值。

## 4. GO Gate

cluster-confirmed执行事件：

1. 数量>=50；
2. 20日平均active>=1%；
3. 中位数>0；
4. 胜率>52%；
5. 三个固定时期至少两个平均active>0；
6. bootstrap 95%下界>0；
7. 相对全部事件平均active提升>=1个百分点或胜率提升>=5个百分点。

均值改善但样本不足为MARGINAL；均值不改善为NO-GO。

## 5. 失败记录

增强账本必须保留同伴组层级、代码、成员数、peer count、密度、指数趋势和原结构/执行/结果失败原因，供后续判断“孤立突破、板块同步、拥挤末端”的差异。
