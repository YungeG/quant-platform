# 低换手选股 × Livermore 不对称持仓结论

- **裁决：MARGINAL / NO DEPLOY**
- **窗口：** 2016-01-04—2026-08-25
- **数据量：** 10,604,795条股票日记录
- **候选：** 298个信号日、419只不同股票
- **初始资金：** 40万元

## 一句话结论

**Livermore式“小仓试错、只给赢家加仓、每日止损、让利润运行”确实改善了同一批低换手突破候选，但改善幅度不足以把策略提升到可靠可部署水平。**

这次没有复现旧框架的夸张高收益；在T日收盘决策、T+1开盘执行、涨跌停阻塞、100股整手和双边费用下，主策略仅获得4.02% CAGR、0.297 Sharpe和-41.93%最大回撤。

## 1. 冻结策略对比

| 策略 | CAGR | Sharpe | 最大回撤 | 平均股票仓位 | 交易数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| **Livermore三段加仓** | **4.02%** | **0.297** | **-41.93%** | 43.10% | 682 |
| 不加仓、首次买满25% | 2.42% | 0.221 | -55.79% | 67.81% | 458 |
| 固定持有20日 | -8.74% | -0.288 | -66.99% | 57.42% | 610 |
| 同股票池等权基准 | 0.67% | 0.148 | -48.74% | 100% | 0 |
| 既有低换手Top-20周频 | 9.73% | 0.441 | -48.93% | 约100% | 周频换仓 |

## 2. Livermore管理确实有增量

相对不加仓版本：

- CAGR：2.42% → **4.02%**；
- Sharpe：0.221 → **0.297**；
- 最大回撤：-55.79% → **-41.93%**；
- 平均股票仓位：67.81% → **43.10%**。

相对固定持有20日，止损和赢家持有将负收益策略从CAGR -8.74%提升至+4.02%。因此“不要摊平亏损，只给盈利仓增加风险”在这批候选上不是空话。

但它没有优于原低换手Top-20的整体风险收益：回撤改善约14.3%，CAGR从9.73%降至4.02%，Sharpe也从0.441降至0.297。

## 3. 固定时期

| 时期 | CAGR | Sharpe | 最大回撤 |
| --- | ---: | ---: | ---: |
| 2016—2019 | +10.86% | 0.644 | -20.99% |
| 2020—2022 | **-3.82%** | -0.064 | -32.94% |
| 2023—2026 | +3.43% | 0.270 | -31.18% |

三个时期中两个为正，满足方向一致性的最低要求，但2020—2022失败，最新时期的收益质量也较弱。

## 4. 收益集中度是主要问题

- 11个自然年只有5年盈利；
- 最佳年份2019收益 **+69.43%**；
- 剔除2019后，其余年份几何年化为 **-1.22%**；
- 2026年截至数据末端为 **-12.23%**。

已平仓交易胜率只有18.18%，中位交易收益-8.26%，平均交易收益-1.94%。策略依赖少数大赢家补偿大量小亏损，符合Livermore收益形态，但当前样本不足以证明这种右尾收益能够稳定重复。

## 5. 成本与执行

- 成本前CAGR：5.13%；
- 成本后CAGR：4.02%；
- CAGR保留率：78.33%，通过70% Gate；
- 累计费用约60,974元；
- 买入阻塞率0.88%；
- 持仓缺失估值率1.34%；
- 平均持有30.3个交易日，中位20日；
- 233次首次进入、218次盈利加仓、119次硬止损、112次移动止损。

执行完整度Gate通过，结果不是由假设涨停成交或忽略费用产生。

## 6. Gate

| Gate | 结果 |
| --- | --- |
| CAGR>0且Sharpe>=0.60 | **FAIL**：Sharpe 0.297 |
| 回撤较原Top-20改善至少20% | **FAIL**：仅改善约14.3% |
| 三个时期至少两个盈利 | PASS |
| 优于固定持有管理 | PASS |
| Pyramiding相对不加仓有增量 | PASS |
| 成本后保留至少70% CAGR | PASS |
| 成交阻塞与估值缺失合格 | PASS |

总裁决按预承诺规则为 **MARGINAL**。

## 7. 数据边界

1. 没有完整历史ST名称/风险警示事件权威；
2. 使用`PctChange`重建连续复权价格，而非正式公司行动事件流；
3. 复权单位用于收益记账，原始100股整手只在成交时约束；
4. 历史区间已被相关研究观察，不是virgin OOS。

因此即使所有Gate通过，也只能达到research-grade。

## 8. 最终判断

- **Livermore不对称持仓思想：保留。** 数据证明其优于一次性重仓和机械20日持有。
- **当前“低换手Top-20后等待突破”的完整策略：不部署。** 收益低、Sharpe不足、年度集中严重。
- **不能继续在同一数据上调整8%/12%、5%/10%、突破窗口或持仓数。**

本轮最有价值的发现不是“找到了策略”，而是：**Livermore管理能够改善风险，但低换手突破这一入场条件没有提供足够稳定的底层edge。** 若继续，必须把“纯低换手入场＋冻结Livermore管理”作为新的预注册候选，而不是在本轮结果上补参数。
