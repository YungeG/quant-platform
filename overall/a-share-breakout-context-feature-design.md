# 突破回踩上下文特征预注册设计

- **状态：** frozen before acquisition
- **基础样本：** 原205个T+1可执行突破回踩事件；形态和收益保持不变
- **目标：** 判断已有高权限代理数据能否事前区分成功和失败回踩

## 1. 决策时点

所有特征使用恢复触发日T收盘时已可见数据；交易仍在T+1开盘。缺失值保持缺失，不前向填充。

## 2. 五个冻结假设

### H1 筹码拥挤

接口：`cyq_perf`，T日精确记录。

- 特征：`winner_rate`；
- 预期：winner_rate越高，20日active越低；
- 辅助记录：加权平均成本及T日收盘相对成本。

### H2 资金确认

接口：`moneyflow_ths`，T日精确记录。

- 特征：`net_amount_rate`；
- 预期：净流入率越高，20日active越高。

`moneyflow_dc`只作独立来源诊断，不参与五项主检验。

### H3 涨停拥挤

接口：`limit_list_d`，T及此前4个交易日。

- 特征：该股票5日涨停/炸板记录数量；
- 预期：近期记录越多，20日active越低。

### H4 游资拥挤

接口：`hm_detail`，T及此前4个交易日。

- 特征：5日游资净买入绝对额/流通市值；无记录为0，只有在日期查询完整时成立；
- 预期：游资强度越高，20日active越低。

### H5 分析师修正

接口：`report_rc`，T前180个自然日。

对每个预测季度，在T和T-30日分别保留每家机构当时最新EPS预测；选择T日覆盖机构最多的、年份不早于事件年份的最近预测季度。两端均至少3家机构才有效。

- 特征：`median_eps_T / median_eps_T_minus_30 - 1`；
- 预期：修正越高，20日active越高。

## 3. 统计合同

每个特征独立计算：

- 可用样本数；
- Spearman相关系数及双侧p值；
- 2,000次固定种子bootstrap 95%区间；
- 2016—2019、2020—2022、2023—2026固定时期相关方向；
- 成功/失败事件中位数。

五项主检验使用Holm-Bonferroni校正，family alpha=5%。

## 4. Feature Gate

某特征只有全部满足才可进入前向Shadow：

1. 总可用样本>=80；
2. 至少两个固定时期各>=15个样本；
3. 总体相关方向符合预期；
4. bootstrap 95%区间不跨0；
5. 至少两个固定时期方向与总体一致；
6. Holm校正后p<0.05。

样本或稳健性不足但方向正确为MARGINAL；方向错误为NO-GO。

## 5. 边界

本轮只选择可进入Shadow的上下文特征，不修改原突破回踩规则，不按结果搜索阈值，不构建多因子打分或机器学习模型。
