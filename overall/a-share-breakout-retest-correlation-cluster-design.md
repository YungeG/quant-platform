# 突破回踩动态相关聚集预注册设计

- **状态：** frozen before execution
- **基础事件：** 原4,447个突破事件和失败账本保持不变
- **目标：** 不依赖固定行业分类，用事前收益共振识别题材、产业链或风格形成的动态同伴群

## 1. 候选同伴

对每个突破事件T：

- 找出T及此前4个交易日内发生突破的其他股票；
- 当前股票自身排除；
- 同日其他突破可使用，因为均在T日收盘后识别。

## 2. PIT相关性

- 使用T-60至T-1的日收益，不包含突破日，避免共同跳涨机械抬高相关性；
- 至少50个共同有效观测；
- Pearson相关系数>=0.60视为有效动态同伴；
- 逐事件记录全部候选数、有效相关同伴数、相关系数中位数、最高值及同伴股票代码。

## 3. 冻结动态聚集条件

`correlation_cluster_confirmed`同时满足：

- 最近5日有效相关同伴突破数>=2；
- 有效同伴相关系数中位数>=0.65。

不使用行业指数、行业宽度或个股行业排名；不扫描60日、5日、0.60、0.65或2只等参数。

## 4. GO Gate

确认后的可执行回踩事件全部满足：

1. 数量>=50；
2. 20日平均active>=1%；
3. 20日中位数>0；
4. 胜率>52%；
5. 三个固定时期至少两个平均active>0；
6. bootstrap 95%下界>0；
7. 相比全部事件平均active提升>=1个百分点或胜率提升>=5个百分点。

均值改善但样本/稳健性不足为MARGINAL；均值不改善为NO-GO。

## 5. 后续边界

本轮结果不能用于修改相关阈值。若方向性为正但样本不足，只能冻结为前向shadow规则；若为负则停止价格相关聚集路线。
