# A股价值×质量数据审计

## 结论

**当前DuckDB不能诚实回测ROE/ROA质量因子。** 不进入策略建模，避免制造财报未来函数和幸存者偏差。

## 证据

### FinancialIndicatorData

- 100,300行；
- 仅1,200只股票；
- `AnnDate`非空数：**0**；
- `EndDate`完整，但不能知道财务指标何时对市场可见；
- 43,837个`Symbol + EndDate`组合存在重复行；
- ROE/ROA同时可用比例约98.3%，但没有发布日期后不可用于PIT回测。

### IncomeData

- 92,968行；
- `AnnDate`和`EndDate`完整；
- 仍仅覆盖1,200只股票；
- 15,267个`Symbol + EndDate`组合有多个版本；
- 数据看起来是受限股票集合，不足以构造历史全市场股票池，存在明显选择/幸存者风险。

### FundamentalData

- 11,114,033行、5,886只股票；
- 2015—2026每日流通市值完整；
- 正`PETTM`覆盖率约72%—92%；
- `PB`、`PETTM`为每日PIT估值字段，可用于价值因子。

## 决策

1. ROE/ROA质量因子：**DEFER / DATA-BLOCKED**；
2. 不用`EndDate + 固定滞后`伪造`AnnDate`；
3. 不在1,200只受限集合上宣称全市场质量alpha；
4. 下一步缩减为可诚实执行的每日PIT价值复合：`EP = 1/PETTM`与`BP = 1/PB`；
5. 获得完整财报公告版本和历史股票覆盖后，质量因子必须作为新研究重新预注册。
