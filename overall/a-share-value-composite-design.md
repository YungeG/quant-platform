# A股PIT价值复合策略预注册设计

- **状态：** frozen before execution
- **背景：** ROE/ROA缺少公告日期且仅覆盖1200只股票，质量因子已判定DATA-BLOCKED；本轮仅使用每日PIT估值字段
- **窗口：** 2016-01-01—数据库最新完整日

## 1. PIT股票池

每63个交易日形成一次组合：

1. 上市至少252个交易日；
2. 未停牌，收盘价至少5元；
3. 过去20日平均成交额位于全市场前50%；
4. 流通市值前500只；
5. `PETTM > 0`、`PB > 0`；
6. T日收盘决策，T+1开盘执行。

## 2. 冻结因子

- `EP = 1 / PETTM`；
- `BP = 1 / PB`；
- 每个决策日分别执行MAD去极值、申万一级行业与对数流通市值中性化、z-score；
- 主分数：`0.5 × EP_z + 0.5 × BP_z`；
- 不搜索权重、估值上下限或其他价值指标。

## 3. 冻结组合

1. **EP+BP composite-50（主策略）：** 分数最高50只；
2. **EP-only-50：** 中性化EP最高50只；
3. **BP-only-50：** 中性化BP最高50只；
4. 已持有且仍在目标集合的股票不强制再平衡；掉出集合全部卖出，新进入股票按NAV的1/50购买。

不增加质量过滤、动量过滤、低波过滤或行业上限。

## 4. 执行

- 100股整手；
- 买入停牌/一字涨停最多重试3日；
- 卖出停牌/一字跌停持续顺延；
- 买入费用13bp，卖出费用18bp；
- 复权单位连续估值，原始开盘决定整手金额。

## 5. 基准

- `top500_cap`：季度Top-500按PIT流通市值加权；
- `top500_equal`：同股票池等权；
- 基准在决策后下一开盘生效，不扣成本。

## 6. 固定时期

- 2016—2019
- 2020—2022
- 2023—2026

## 7. Gate

主策略全部满足才为GO：

1. 净CAGR至少高于`top500_cap` 1个百分点；
2. Sharpe至少高于基准0.10；
3. 最大回撤不得比基准恶化超过5个百分点；
4. 三个固定时期至少两个净超额CAGR > 0；
5. 剔除最佳年份后CAGR >= 0；
6. 成本后保留至少90%的成本前CAGR；
7. 年化单边换手 <= 2.0；
8. 平均持仓至少40只，买入阻塞/整手失败率 <= 10%，估值缺失率 <= 2%。

净CAGR和超额为正但未全部通过时为MARGINAL；净CAGR<=0或无正超额时为NO-GO。

## 8. 解释边界

- 本轮只能判断价值，不代表价值×质量；
- 正PE过滤会排除亏损公司，但不能替代质量因子；
- 样本不是virgin OOS；
- 不得在结果后增加ROE代理、固定财报滞后或调整EP/BP权重。
