# A股股债金多资产配置最终结论

- **裁决：GO**
- **窗口：** 2017-01-03—2026-08-25
- **资产：** 沪深300ETF、国债ETF、黄金ETF
- **调仓：** 季度，T+1开盘
- **成本：** ETF单边8bp

## 一句话结论

**这是目前第一条通过全部预注册Gate、具有实际配置价值的路线。** 固定股债金和动态风险预算都显著降低回撤；复杂ERC相对固定权重确实改善了Sharpe和回撤，但ERC与更简单的波动率倒数几乎没有经济差异。

## 2. 预注册主策略全部通过

固定30/50/20：

- 回撤相对全股票改善77.5%；
- Sharpe比全股票高0.59；
- CAGR 6.42%，高于60/40的4.71%；
- 三个固定时期CAGR全部为正；
- 2018收益-3.72%，显著优于全股票-24.16%和60/40的-12.62%；
- 2022收益-3.41%，显著优于全股票-20.14%和60/40的-11.61%；
- 成本后保留99.66%的成本前CAGR；
- 年化单边换手0.13；
- 40万元账户所有非零目标均能购买至少100份。

因此主策略正式`GO`。

## 3. 分时期稳定性

弱阶段仍保持正复利，没有依赖单一牛市时期。

## 4. 复杂风险平价是否值得

ERC和波动率倒数都通过复杂度Gate：

- Sharpe约1.65—1.69；
- 最大回撤约-3.2%；
- 三个时期和所有自然年均为正；
- 2018和2022也取得正收益；
- 年化单边换手仅约0.15。

但两者配置和结果几乎完全一致：

| 指标 | 波动率倒数 | ERC | 差异 |
| --- | ---: | ---: | ---: |
| CAGR | 4.96% | 4.93% | 波动率倒数+0.03pp |
| Sharpe | 1.655 | 1.686 | ERC+0.031 |
| 最大回撤 | -3.18% | -3.17% | 0.01pp |
| 债券权重 | 77.7% | 78.1% | 0.4pp |

正式评分中ERC略胜，但经济差异不足以抵消协方差优化复杂度。**实际实施优先选择波动率倒数，而不是ERC。**

## 5. 三种可用风险档位

### 增长档：三资产1/N

- CAGR最高：8.13%；
- Sharpe 0.953；
- 最大回撤-12.51%；
- 无参数、最简单。

### 平衡档：固定30/50/20

- CAGR 6.42%；
- 最大回撤-9.49%；
- 无估计误差；
- 推荐作为默认核心配置。

### 保守档：波动率倒数

- CAGR 4.96%；
- 最大回撤-3.18%；
- Sharpe 1.655；
- 平均约78%国债，目标是资产保全而非高收益。

## 6. 为什么这条路线成功

与个股策略不同，它不依赖预测哪只股票上涨，而是利用：

1. 股票、国债和黄金的不同风险来源；
2. 季度再平衡出售相对上涨资产、补充相对落后资产；
3. 债券和黄金对A股熊市的缓冲；
4. 极低换手使成本几乎不影响结果。

收益来自资产配置和风险预算，不应称为股票alpha。

## 7. 数据与风险边界

- 使用ETF二级市场价格，已内含基金费用、折溢价和跟踪差异；
- 2017—2026仍是有限样本；
- 国债ETF约78%的动态配置可能受到未来利率上行影响；
- 没有virgin OOS，部署前仍应shadow并按冻结季度规则运行；
- 不应继续加入宏观预测、均线择时或权重扫描。

## 8. 最终推荐

1. **默认：固定30%沪深300ETF＋50%国债ETF＋20%黄金ETF，季度调仓。**
2. 追求更高收益可用三资产各1/3。
3. 最大限度控制回撤可用252日波动率倒数；不需要ERC。
4. 停止继续寻找神奇个股择时，把个股因子仅作为未来小比例卫星仓研究。

**总裁决：GO。**
