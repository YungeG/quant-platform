# A股横截面低换手因子复核结论

- **裁决：MARGINAL / SHADOW-ONLY**
- **数据：** 2016-01-01—2026-08-25
- **组合：** 剔除最小30%流通市值与成交额底部20%，行业/规模中性化后选20只最低换手股票，5日换仓
- **成本：** 单边12bp

## 一句话结论

**这个方向有真实候选edge，明显强于此前的技术择时和行业轮动，但当前20只实用组合仍未达到可直接部署标准。**

低换手信号不是随机噪声：它在三个固定时期都取得正active edge，真实组合击败全部20个随机安慰剂；但集中表达后换手仍高、成本侵蚀大，净Sharpe只差一点未过预承诺Gate。

## 1. 主结果

| 指标 | 结果 | Gate |
| --- | ---: | --- |
| 净active edge / 5日 | **+0.111%** | >0，PASS |
| 净active Sharpe | **0.469** | >=0.50，FAIL |
| 绝对CAGR | **9.73%** | >0，PASS |
| 组合Sharpe | 0.441 | 诊断 |
| 最大回撤 | **-48.93%** | 诊断 |
| 年化one-way turnover | **16.84** | <=16，FAIL |
| 选中收益缺失率 | 1.05% | <=2%，PASS |
| 平均实际有收益股票数 | 19.79/20 | 诊断 |
| 最新100股整手可行 | 20/20 | PASS |

实用过滤后股票池基准CAGR约 **4.93%**、Sharpe 0.307、最大回撤-45.80%；低换手20只组合扣成本后CAGR **9.73%**、Sharpe 0.441，但最大回撤略差。

## 2. 分期稳定性

| 时期 | 净active edge / 5日 | Active Sharpe |
| --- | ---: | ---: |
| 2016—2019 | +0.094% | 0.611 |
| 2020—2022 | +0.024% | 0.093 |
| 2023—2026 | +0.203% | 0.709 |

三个时期方向都为正，但2020—2022几乎没有经济意义，说明edge具有明显状态依赖。

## 3. 信息含量与成本

- 成本前active edge约 **+0.191%/5日**，成本后剩 **+0.111%**；约42%的毛edge被交易成本吃掉。
- 成本前active Sharpe约 **0.804**，成本后降至 **0.469**。
- 20个随机安慰剂的Sharpe中位数为 **-1.287**，且没有一个超过真实因子，说明结果并非“随便重排股票也能得到”。
- 但安慰剂高换手导致成本更高，因此该比较同时奖励了低换手信号自身的持仓稳定性；不能把差值全解释成预测能力。

## 4. 与既有研究的关系

- 既有分散组合 `turnover20_pct20_size5` 滚动研究净Sharpe约1.25，但持仓数量过大且不是未触碰OOS。
- 既有Top4—Top6集中组合Sharpe仅0.39—0.48并全部FAIL。
- 本次Top20结果介于两者之间：保留了正edge和可执行手数，但净Sharpe与换手刚好未过Gate。

这形成一致的容量梯度：

```text
大规模分散表达：统计表现较好，零售难执行
Top20表达：MARGINAL
Top4—Top6表达：FAIL
```

## 5. 最新未触碰窗口

2026-07-22之后仅5个完整/近完整调仓期，且选中收益缺失率40%，状态为 **HOLDOUT_INCOMPLETE**，不能用于确认或否定策略。

## 6. 仍存在的数据限制

1. ST判断包含当前名称和全历史价格限制代理，不是完整PIT状态权威；
2. 计划退出收益缺失时按现金0收益处理，而非完整延迟退出执行；
3. 组合收益尚未逐单模拟涨跌停卖出、100股取整后的完整资金占用和最低佣金；
4. 本次是独立实现复核，但历史区间仍已被此前研究看过，不是virgin OOS。

## 7. 最终判断

- **因子方向：保留。**
- **普通账户Top20实盘：暂不部署。**
- **建议角色：研究型shadow候选。**
- **总裁决：MARGINAL / SHADOW-ONLY。**

不应继续在同一历史区间调窗口、Top-N或阈值。下一步只有两条诚实路径：积累新的前向样本；或事先冻结一个降低换手的持仓缓冲规则，并把它视为新候选而非对本次结果补丁。
