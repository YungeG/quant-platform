# 突破回踩题材概念聚集预注册设计

- **状态：** frozen before execution
- **数据：** 东方财富`dc_member`、`dc_index`，通过已批准xiaodefa代理按历史交易日获取
- **基础样本：** 原突破回踩V2中具有可执行结果的事件

## 1. 动态候选同伴

对每个执行事件的突破日T：

- 候选同伴为T及此前4个交易日发生突破的其他股票；
- 查询目标股票和候选同伴在T日所属东方财富概念；
- 仅保留`idx_type=概念板块`；
- 使用T日`up_num+down_num`作为概念规模。

## 2. 冻结概念过滤

有效概念成员数必须在10—100之间：

- 少于10只容易成为偶然小组；
- 超过100只过于宽泛，接近市场或风格标签。

`concept_cluster_confirmed`要求：

- 至少存在一个有效概念；
- 目标股票与至少2只近期突破同伴共享该概念。

即同一概念最近5个交易日至少出现3只同步突破股票。多个概念满足时保留全部证据，不挑选表现最佳概念。

## 3. PIT和执行

- 概念成员及规模均按突破日查询；
- 不使用当前成员回填历史；
- 数据缺失单列，不视为无概念；
- 原形态、执行和收益不重新计算或修改。

## 4. GO Gate

概念聚集确认事件全部满足：

1. 数量>=30；
2. 20日平均active>=1%；
3. 中位数>0；
4. 胜率>52%；
5. 三个固定时期至少两个平均active>0；
6. bootstrap 95%下界>0；
7. 相比全部事件平均active提升>=1个百分点或胜率提升>=5个百分点；
8. 目标和候选同伴概念数据完整率>=95%。

均值改善但样本/稳健性不足为MARGINAL；均值不改善为NO-GO。

## 5. 失败记录

增强账本保留：查询完整性、共享概念代码/名称/规模、共享同伴、同伴数量、原结构失败和持有结果。不得在结果后按题材名称选择赢家。
