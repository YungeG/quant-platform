# 低换手选股 × Livermore 不对称持仓回测设计

- **状态：** frozen before execution
- **目的：** 检验“低换手因子负责选股，Livermore规则负责确认、加仓和退出”能否把已有MARGINAL因子变成更可靠的账户策略
- **窗口：** 2016-01-01—数据库最新完整日
- **初始资金口径：** 40万元；收益模拟使用复权价格和资金权重，100股整手另报诊断

## 1. 数据与证据等级

使用 `/srv/bcache-8t/ygguo/duckdb/quant-a50/quant_a50.duckdb`：

- 上市与退市日行情并集；
- `FundamentalData.CircMV`，仅向前修复流通股数；
- `PctChange` 重建连续复权开高低收；
- 申万历史行业成员用于行业中性化；
- T日收盘决策，T+1开盘执行。

数据库没有完整历史ST名称、正式复权因子和公司行动事件流，因此最高结论为 **research-grade**，不能声明decision-grade或实盘授权。为避免当前名称造成未来函数，本次不使用当前名称做历史ST排除；以大中盘和流动性过滤降低风险，并单列此限制。

## 2. PIT股票池与低换手信号

每个交易日只使用截至当日的数据：

1. 上市至少252个交易日；
2. 当日未停牌，收盘价至少5元；
3. 过去20日平均成交额位于横截面前50%；
4. 流通市值位于横截面前50%；
5. `turnover20 = mean(Amount / PIT-repaired CircMV, 20 sessions)`；
6. 按日MAD去极值，行业与对数流通市值中性化；低换手分数越高越好。

每5个交易日形成候选榜，先取低换手Top-20，再要求：

- 当日复权收盘价高于此前20日最高收盘；
- 当日复权收盘价高于60日均线。

没有同时满足者则持有现金。不搜索窗口、Top-N、股票池阈值或趋势条件。

## 3. 主策略：Livermore pyramiding

- 最多4只股票；
- 每只最终目标25% NAV，分为3个等额单位，每单位为当时NAV的 `1/12`；
- 首次进入只买1单位；
- 相对首次成交价盈利达到5%后加第2单位；达到10%后加第3单位；
- 每日最多加1单位；只加盈利仓，永不向亏损仓摊平；
- 股票掉出候选榜不卖出；只有退出规则触发才卖。

退出每日收盘检查，下一可成交开盘执行：

- 硬止损：收盘 <= 加权平均成本 × 0.92；
- 移动止损：收盘 <= 持仓后最高收盘 × 0.88；
- 实际止损线取两者较高值；
- 无固定持有期限，允许赢家继续运行。

## 4. 执行与费用

- 所有订单在信号后下一交易日开盘执行；
- 买入遇停牌或一字涨停，最多重试3个交易日，之后取消；
- 卖出遇停牌或一字跌停，持续顺延直到可成交；
- 一字限制采用保守数值判定：开高低收相等且涨跌幅绝对值至少4.5%；
- 先卖后买；卖出待执行时取消同股加仓；
- 佣金与滑点：买入13bp；卖出另加5bp印花税，共18bp；
- 复权价格用于连续收益和持仓记账，原始价格用于40万元/100股整手可行性诊断。

## 5. 冻结对照组

1. **No-pyramid：** 相同候选、硬止损和移动止损；首次进入直接买25%，不加仓。
2. **Fixed-20：** 相同候选；首次进入直接买25%，持有20个交易日后退出，不使用止损和加仓。
3. **Universe benchmark：** 同日大中盘高流动性股票池的复权日收益等权均值，不扣成本。
4. **既有低换手Top-20：** 引用已冻结的5日再平衡结果作为外部对照，不重新优化。

## 6. 时间折与报告

固定折：

- 2016—2019
- 2020—2022
- 2023—2026

每个策略报告：

- CAGR、年化波动、Sharpe、最大回撤、Calmar；
- 相对股票池基准的CAGR差；
- 年度收益与三个固定折；
- 平均/最大仓位、现金占比、交易次数、持有期；
- 加仓次数、止损次数、移动止损次数；
- 买卖阻塞率、费用、gross-to-net retention；
- 40万元100股整手覆盖。

## 7. 预承诺Gate

### GO

全部满足：

1. 主策略净CAGR > 0，Sharpe >= 0.60；
2. 最大回撤不超过39.2%（较既有Top-20的48.93%至少改善20%）；
3. 三个固定折至少两个CAGR为正；
4. 主策略相对Fixed-20满足以下之一：Sharpe高至少0.10；或最大回撤改善至少20%且CAGR少不超过3个百分点；
5. Pyramiding相对No-pyramid至少改善CAGR或Sharpe，且最大回撤不得恶化超过5个百分点；
6. 费用后保留至少70%的费用前CAGR；
7. 买入阻塞率 <= 10%，缺失估值日 <= 2%。

### MARGINAL

净CAGR和Sharpe为正，回撤得到实质改善，但未通过全部稳健性、增量或成本Gate。

### NO-GO

净CAGR <= 0、Sharpe <= 0，或最大回撤未能至少改善10%（仍差于-44.0%）。

本轮只运行上述三种冻结策略。不得在看到结果后改成其他止损阈值、加仓台阶、突破窗口、持仓数或股票池分位并把新结果并入本Gate。任何后续变体必须重新预注册并视为新候选。
