# A股股债金多资产配置预注册设计

- **状态：** frozen before execution
- **目标：** 寻找可部署的回撤控制和稳定复利，而非股票选择alpha
- **资产：** `510300.SH`股票、`511010.SH`国债、`518880.SH`黄金
- **窗口：** 2017-01-01—2026-08-25；2016年用于动态权重预热
- **资金：** 40万元

## 1. 冻结策略

1. `all_equity`：100/0/0。
2. `60_40`：股票60%、国债40%、黄金0%。
3. `fixed_30_50_20`：股票30%、国债50%、黄金20%，预注册主策略。
4. `equal_1n`：三资产各1/3。
5. `inverse_vol`：过去252日波动率倒数归一化。
6. `erc`：过去252日日收益协方差的long-only等风险贡献权重。

动态权重只使用信号日及之前252个交易日，不预测收益，不使用杠杆、不做空、不设主观权重上下限。

## 2. 调仓和执行

- 每63个共同交易日形成一次信号；
- T日收盘计算权重，T+1开盘调仓；
- 调仓日前夜收益由旧持仓承担，开盘后切换到新权重；
- 权重在两次调仓之间随资产价格自然漂移；
- ETF单边交易成本8bp；基金费率和跟踪差异已包含在市场价格；
- 主回测使用连续权重；同时报告40万元、100份整手是否可行。

## 3. 固定时期和压力年

- 2017—2019
- 2020—2022
- 2023—2026

压力年：2018、2022。报告年度收益、CAGR、波动率、Sharpe、最大回撤、Calmar、季度/年化换手和成本保留率。

## 4. 主策略Gate

`fixed_30_50_20`全部满足才为GO：

1. 最大回撤较`all_equity`改善至少35%；
2. Sharpe至少高于`all_equity` 0.20；
3. CAGR为正，且不低于`60_40`超过1个百分点；
4. 三个固定时期CAGR全部为正；
5. 2018和2022收益均高于`all_equity`，且至少一个压力年高于`60_40`；
6. 成本后保留至少98%的成本前CAGR；
7. 年化单边换手 <= 1.0；
8. 每次非零目标权重在40万元账户均至少可买100份。

CAGR为正且回撤改善显著、但未通过全部Gate时为MARGINAL；CAGR<=0或回撤改善不足20%时为NO-GO。

## 5. 复杂度Gate

`inverse_vol`或`erc`只有满足以下之一才可取代固定权重：

- Sharpe至少高于`fixed_30_50_20` 0.05；或
- 最大回撤再改善至少5个百分点，同时CAGR少不超过1个百分点。

否则裁决必须选择更简单的固定权重，不因动态模型看起来更专业而保留。

## 6. 解释边界

- 多资产GO代表配置和风险控制可用，不代表获得股票alpha。
- 不在本轮加入趋势过滤、估值择时、宏观预测或参数扫描。
- 不调整30/50/20、60/40、252日窗口或季度频率以追逐结果。
