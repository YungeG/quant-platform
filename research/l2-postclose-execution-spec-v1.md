## 3. 统计方法冻结

以下规定在本轮新资金画像及后续统计之前确定。当前真实数据未获资格，统计实现可以用合成测试验证，但不会因此接受真实来源。

### 3.1 共同总体与资格

每个 W/H 单元格，保留完整、按官方交易日期对齐的锚点轴；F/P/价格标签已知且合格的行才参与相对二值规则的分组差。F/P未知不进入对照；同日三只股票不当作独立日期样本。

推断须同时满足：独立前瞻队列及可用时间资格；两组各≥20个成熟合格锚点；共同合格日期≥10个自然周；从锚点区间起点固定切分、至少8个长度 L=W+H 的非重叠完整合格日历块。含缺失的块不能移位或拼接。未满足时仅报告缺口和已有描述，不调用重采样。

本轮28日已观察数据的前瞻资格为 false。不能通过 CLI 开关将其变为 holdout。报价与字段的本地哈希也不能打开该门槛。

### 3.2 移动块重采样

- L=W+H，随机种子0，B=20000。
- 起点集合为完整锚点轴的所有连续L日块；每次有放回抽取 ceil(N/L) 个块，拼接后截为 N 个位置，块内顺序不变。
- 同一 W/H 下三只股票使用同一批位置；资格缺失仍为缺失，不能填0或跳过后补满。
- 重新计算组间上涨占比差 Δ*。某次缺少任一组，该格该次无效；有效次数<95%B，该格不生成推断。
- 每一格的观测差为 Δ。采用居中差 E*=Δ*−Δ，正向零假设检验近似 p=(1+count(E*≥Δ))/(1+B_valid)。这是依赖块重采样假设的近似检验，不是有限样本精确检验。

### 3.3 家族、多重比较与区间

- 主口径所有预登记格为同一家族 M。无资格格保留在 M 中；仅在 Holm 排序的内部占位使用1，其对外原始／调整p均保持缺失，不伪装成真实计算结果。
- Holm–Bonferroni 正向p调整，家族α=0.05。
- 同时报保守的 Bonferroni basic bootstrap 区间：令 a=α/(2M)，区间为 [Δ−q(E*,1−a), Δ−q(E*,a)]，截到概率差的理论范围[−1,1]。该区间较 Holm 判定保守，绝不把未校正95%区间称为家族区间。
- 有效抽样次数和尾部抽样分辨率必须记录；20,000次并不消除统计假设、长序列依赖或小样本的不确定性。
- 辅助阈值只作敏感性描述，不代替主口径、不参加挑赢家。

### 3.4 结果解释

“附加关联迹象”同时要求点估计Δ≥0.10、平均价格变化差>0、Holm正向p≤0.05且保守家族区间下界>0。它不等于已证实真实增量至少10个百分点，更不代表独立因果、净收益或交易授权。

保守家族区间上界≤0时，可以记录未支持正向关联／反向证据；其余情况均证据不足或未达点估计门槛。不以某个其他W/H挽救失败格。

## 4. 原始文件验收与安全失败

- 参数和120格预算在文件读取前验证。
- 逐文件检查路径、字节数、CRC、SHA-256、CSV列数、标的／日期和单位；被破坏的文件明确失败，不按原表中位数补齐。
- 日期缺失按独立日历保留，不从文件列表推断“交易日一定完整”。日历重建证据只声明其明确覆盖的日期与用途。
- 来源身份、订单号作用域、真实成交代码、竞价归类、价格来源、公司行为可比段、可用时间均单独报告；技术通过不能替代语义通过。
- 交易所公开协议、其他供应商文档和相似数据集卡只能作为线索，不能自动证明本地百度网盘文件来自对应供应商或拥有同样语义。
- 任何统计门槛失败均缺失或未执行，不写成0收益、失败概率或上涨率0%。
