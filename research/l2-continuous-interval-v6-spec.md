# 连续区间趋势规格 v6：换手持续性、50万组资金、价格验证

用户已确认：以一段时间趋势为主，不以某一天资金与涨跌对应作判断。本轮仅既有五股（300855.SZ、688122.SH、688137.SH、688202.SH、688655.SH），20260901–20261019；不称全市场研究。保留旧v1–v5代码、规格、结果与资格状态，新目录输出。本地事后描述，不是正式Platform Backtest／Validation、持仓识别或新OOS。

## 1. 区间与换手先固定

- 同一股票、连续**5／10／20个交易日**为主体；完整市场日历沿用v4有依据的29日序列，保留休市规则与来源局限。3日不作为本轮主结论。
- 中间低换手日照常纳入，不先按单日>10%删除再拼窗口；现金异常／缺失同样不跳过，也不当0。窗口失败保留原因及日期。
- 普通流通换手`turnover_rate`（%），不混自由流通换手。区间日均>10%为“活跃区间候选”，**不是自动判定强趋势**；报告>10%的日数／比例、最大连续高换手天数、最高单日值。不新增“必须多数天达标”的隐藏门槛，也不把累计换手理解为同一筹码转手遍数。
- 区间期末可观察，不能回填至期初当事前选股条件。所有日期已是历史或本地已见样本，不追认为前瞻。

## 2. 资金持续性

- 每日先按同股／日／侧交付引用组的全日已成交额≥50万元分类，再跨日汇总；不跨日合并同号，不按主动部分重新判大小。
- 列累计买／卖金额、组差、源已判主动差、被动差、未判差、全M及相对M的比率，均保留精确人民币×10000整数及清楚显示单位。
- 组差正／负日、主动差正／负日分别计数，最大连续正日数；组偏买条件沿用“区间组差>0且正差日超过半数”，主动支持同理。未知不作false对照或0额。
- 单日集中度用**最大1／2个正差日占全部正差日金额之和**，不是除净差（避免抵消后超过100%误读）；无正差日时缺失。它是集中度提示，不临时新增数值门槛筛最佳收益。
- 计算累计组差曲线从段内历史高点的最大回落金额，仅为差额曲线，不是账户／PnL／持仓净值回撤。不能据持续正差说同一资金还在。
- 最新5/10/20全部报告；历史同窗口全部留存，不只挑赢家。重点候选按换手候选、组偏买与主动支持描述，不用价格收益排名；不同长度和重叠窗口不相加。

## 3. 价格是独立的一轴

- 本轮不再使用单日开盘→末价涨幅替代区间趋势。
- 补查独立价格／调整定义、公司行动及有效日；只有覆盖相应区间可比性时才给价格趋势确认。不能因为同源前收盘衔接平滑、两个目录close相同或没搜到公告，就推断没有除权。
- 原始源行情日末价序列及前收盘衔接检查可以作为**未接纳的原始观察**列出；不是收益、跨日经济增值或P通过。在可比性未闭合时，不输出已合格首尾涨跌率、价格重心／回撤结论或未来上涨概率。原P／price_segment／close_ok不改true。
- 资金／换手资格正常时仍输出，不被独立价格缺口统一抹掉。若整段价格未完成，最终明确这是未完成轴，不宣称总体上涨研究已验证。

单一小型区间计算模块及对应合成测试；不修改平台交易／收益引擎。覆盖低换手日不删、坏日不跳、5/10/20精确长度、换手与现金分别降级、正差集中度分母、单日脉冲与连续正差、未知及金额精度。先一个明确五日样例核验，再运行5股×29日×3尺度的有限完整矩阵并独立复核加总／状态。
