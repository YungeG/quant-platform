# v3补充：逐日金额阶梯与源B/S主动性

本轮是对既有v2本地描述性结果的细化，不是正式Platform Backtest／Validation执行，不新增撮合、费用、库存、PnL或价格预测。原v1/v2代码、规格、原数据与运行不覆盖。范围仍为688122.SH、688137.SH、688655.SH，20260901–20261016的既有28日，不下载历史包、不执行提供方脚本。

## 1. 先冻结定义

- 分组仍为股票／自然交易日／买卖侧／交付引用号。名称保持“编号组代理”，不宣称交易所唯一原单、机构或账户身份。
- 大小按**全日该组累计已成交金额**，不是单笔打印金额、原始申报金额、跨日合计金额或分别按主动／被动累计金额。
- 六个默认互斥区间（人民币）：`[0,50000)`、`[50000,200000)`、`[200000,500000)`、`[500000,1000000)`、`[1000000,5000000)`、`[5000000,+∞)`。下界包含、上界不包含；50万和100万边界与旧定义一致。参数可显式调整，但必须从0开始、严格递增、最多12个下界、每个下界及其万倍整数在支持范围内。本轮不根据涨跌或好看的净差修改分档。
- 空、零、异常引用放**无法归组／大小未知**桶，不计为最小档，不构造0号大组。各侧六档＋未知桶的观察金额必须分别守恒到全M；买侧＋卖侧为2M，不是两份独立市场成交。
- 表格同时列买组额、卖组额、组差的**万元绝对金额**；百分比仅作补充，不代替金额。每档买／卖各侧另列主动、被动、未判主动性金额、数量、源成交腿数及已知编号组数。金额／数量／腿数按角色守恒；同一组可出现多个角色，角色内去重组数不能相加作该档总组数。

## 2. 主动／被动：源标记的有限解释

已绑定同分享D1 `各代码的意义.docx`（SHA-256 `79ce26b0f48f6d56f9d87ad55286b950fe8d5bdc41b4e693e17a7bb19cfcff54`）明确：`B 主动买（叫卖序号<叫买序号），S 主动卖（叫卖序号>叫买序号）`。只读文本及示例，不执行提供方代码。

- 使用原BS字段，规范化只移除代码字段外侧空白／NUL，不全局擦除引用中的NUL。不能从大组大小、A匹配失败或申报量与成交量不同猜主动性。
- 仅在**来源本地时钟连续竞价子集** `09:30≤t<11:30`、`13:00≤t<14:57` 使用该解释。为保守处理边界，11:30整点不纳入；边界、集合竞价与其他时间全部单列“时钟范围外／未判”，不推断一个主动方。这个时钟筛选不是完整交易所阶段／时钟同步认证；未知S/E阶段标志仍不使整日现金消失。
- 子集内要求BS为B/S、两个引用均可按资料规则比较、序号不相等，且标记与资料例子一致。缺号、等号、未知BS、规则冲突均保留未知原因，不反向覆盖源BS，也不使用价格tick-rule填补。
- B：买方腿主动、卖方腿被动；S相反。不是把买方腿都称主动买。源B/S内校验不是独立的交易所撮合先后证明，也不依赖A匹配，更不识别持仓。
- 一个150万元组即使由主动70万元、被动80万元组成，仍整个属于100–500万元档，再在档内分70／80；不得拆后各自重新判大小。
- 所有金额为精确整数人民币×10000。仅显示万元和VWAP时转换。每侧每档 `主动＋被动＋未判＝观察总额`，两侧主动额之和等于已判市场成交额，被动与主动是同笔成交的两腿，不能再相加作市场总额。

## 3. 资格与失败

复用v2受指纹约束的资料／清单／日历及逐日检查，重新校验当前使用的成交和行情文件；不通过手工正向布尔开放。无A不删除，累计金额只诊断，累计量／笔数需精确匹配。

- 完整档位金额需现金日与该侧引用／混组检查通过。某侧缺引用时保留已观察分布和未知桶，但不能把已观察已知档称完整分布。
- 10月12日三股量／笔数差仍未解决：仅留观察明细，完整金额与档差为空，不设为0，不拼接跳日。
- B/S无法判断只降低主动性覆盖，不抹现金或其他编号组事实；未知类别金额不分摊到主动买／卖。
- 主动性完整统计分三类：已判主动买、已判主动卖、未判市场成交额，三者合计M。全档买卖组差之和必为0，不能解释为全市场资金净流入；单档组差也不能与该档主动买卖差混同。报告同时显示覆盖率，不能把仅已判部分占比称全天主动占比。
- 不生成价格P、跨日VWAP、未来收益、上涨概率或真实OOS；28日均已观察。新阶梯是描述分布，不是参数选优的新120格预测实验。

新增一个v3分析CLI和对应测试；复用v2读取／资格及组算术，不改旧代码。CLI每次新目录，先正常单日，再三股正常＋异常小样本，最后现有28日。原始选定读取最多1GiB、单CSV仍≤256MiB，仅两类168个文件，无辅助A前提。缺文件显式失败，独立股票日继续，输出状态不伪装成功。
